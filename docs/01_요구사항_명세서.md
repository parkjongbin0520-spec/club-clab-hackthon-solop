## 과제명
동아리 활동 기록 관리 웹앱

## 개요
동아리 임원이 활동 내역을 기록하고 조회할 수 있는 웹앱을 만든다.
모든 팀이 동일한 필수 기능을 구현하며, 선택 기능으로 차별화한다.

## 팀 구성
- 인원 제한 없음
- 팀장 1명 지정. 팀장이 GitHub 저장소를 생성하고 팀원을 협업자로 추가한다.

## 기술 조건
- 프론트엔드: HTML / CSS / JavaScript
- 데이터 저장: 브라우저 localStorage (별도 서버·DB 불필요)
- 외부 라이브러리는 CDN 방식으로 자유롭게 사용 가능
- 개발 도구: Claude Code 사용 필수

> 담당 교수 판단에 따라 기술 스택은 수업에서 다룬 것으로 대체할 수 있다.

## 필수 기능 (전 팀 공통)
1. **활동 등록** — 활동명, 날짜, 장소, 참여 인원, 메모를 입력해 저장
2. **활동 목록 조회** — 저장된 활동을 최신순으로 표시. 빈 목록일 때 안내 문구 표시
3. **활동 삭제** — 목록에서 개별 활동 삭제. 삭제 전 확인 절차 필요

## 선택 기능 (자유롭게 골라 구현)
- 활동명·장소 키워드 검색
- 기간(시작일~종료일) 필터
- 활동 수정 기능
- 월별 활동 횟수 통계 차트
- 참여 인원 합계 및 평균 표시
- 데이터 JSON 내보내기 / 가져오기
- 반응형 레이아웃 (모바일 화면 대응)

## 입력값 검증 요건
- 활동명은 필수. 비어 있으면 저장 불가
- 날짜는 미래 날짜 입력 불가
- 참여 인원은 1 이상의 정수

## 제출물
1. **GitHub 공개 저장소 1개** (팀당 1개)
   - 저장소명: `hackathon-<팀번호>-<팀이름>`
   - 커밋 5회 이상, 팀원 전원의 커밋 기록 확인 가능할 것
   - 루트에 `CLAUDE.md` 포함 (템플릿 참고)
   - 루트에 `README.md` 포함 (아래 항목 필수)
     - 팀원 명단과 역할
     - 구현한 필수/선택 기능 목록
     - 실행 방법
     - 실행 화면 스크린샷 2장 이상
2. **결과 보고서 PDF** (별도 양식, 2~4쪽)
3. **제출 방법**: 제출 폼에 저장소 URL + 보고서 PDF 업로드
